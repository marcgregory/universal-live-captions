# ADR 0001: Native Stack — .NET 8, C#, WPF, NAudio

Date: 2026-07-31

## Status

Approved

## Context

The product requires a native Windows 10 desktop application that captures system audio (WASAPI loopback), processes audio, runs streaming speech-to-text, and renders an always-on-top caption overlay. The technology must be Windows 10 compatible (build 17763+), support WASAPI, allow low-latency audio processing, be maintainable and testable, and fit the installed development toolchain.

At the time of selection, the development machine had .NET SDK 8 and 10 installed and no Rust toolchain.

## Decision

Adopt **C# / .NET 8 (LTS)** with **WPF** for UI and **NAudio 2.2.1** for WASAPI loopback capture. Structure the application as a .NET solution with layered projects under `src/` (`UniversalCaptions.Core`, `.Audio`, `.Speech`, `.Captions`, `.App`, `.Diagnostics`) and test projects under `tests/`. Use `Microsoft.Extensions.DependencyInjection` for composition and xUnit for testing.

Approved by the user on 2026-07-31.

## Consequences

- .NET 8 LTS supports Windows 10 version 1809 (build 17763) and later; the same code runs on Windows 11.
- NAudio provides a mature, battle-tested WASAPI loopback wrapper, reducing custom COM interop.
- WPF provides native transparent/borderless/always-on-top window support and per-monitor DPI.
- Projects target `net8.0`; only the WPF app project uses `net8.0-windows`.
- The layer separation (Core/Audio/Speech/Captions/App) keeps capture, STT, caption logic, and rendering in separate assemblies with enforced dependency direction.
- Build/test tooling: `dotnet build`, `dotnet test`, `dotnet format`.

## Alternatives Considered

- **Rust + windows-rs**: not installed in the environment; requires substantially more manual WASAPI and Win32 interop for loopback and overlay; higher delivery cost for no MVP benefit.
- **WebView2 + React/TypeScript UI**: adds a WebView2 runtime dependency and web toolchain with no benefit for a caption overlay and a minimal control window.
- **Win32 raw C++**: unmaintainable for this project's scope and testing needs.
- **Electron**: heavyweight, adds Chromium, not justified for a native overlay app.
